# 澄明 · 智能家庭健康中枢

公开演示：<https://herculerrr.github.io/chengming-health-platform/>

这是一个面向家庭用户的医疗服务平台原型，包含：

- 智能预约推荐：根据就诊诉求、医生匹配度和可约时段推荐号源。
- 智医速诊：通过主要症状、持续时间、严重程度和危险信号进行多步骤辅助分诊。
- 可解释路径：展示推荐科室、优先级和预计等待时间。
- 急诊协同：体现 LLM、医学知识图谱、RAG、强化学习和院内资源协同的产品化表达。

## 本地运行

```bash
npm install
npm run dev
```

这是演示原型，分诊结果不替代医生诊断。胸痛、呼吸困难、意识异常等紧急情况请立即联系急救服务。
